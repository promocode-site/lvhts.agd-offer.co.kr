호텔스닷컴 쿠폰 코드 투숙 시기별 정리

예약 마감은 여섯 코드 모두 2026년 9월 30일이고, 달라지는 것은 투숙 마감입니다. 지금 예약해 두면 내년 상반기 숙소까지 코드를 적용할 수 있습니다.

  1. 2026년 12월 31일까지 투숙

    SUMMER20 · SPECIAL10 · DT26 · LP005

    투숙 기간이 공개된 네 코드 모두 사용 가능. 금액 기준으로 SUMMER20(50만원 이하) 또는 SPECIAL10(50만원 초과).

  2. 2027년 1월 1일 ~ 6월 30일 투숙

    DT26 · LP005

    SUMMER20·SPECIAL10은 투숙 기간이 끝나 쓸 수 없습니다. 1박 14만원 3박(42만원)이면 DT26 할인 33,600원, LP005는 21,000원.

  3. 2027년 7월 1일 이후 투숙

    적용 가능한 코드 없음

    투숙 기간이 공개된 네 코드 모두 기간 밖입니다. LP08·MYHOCANCE26은 결제 단계에서 적용 여부를 확인해야 합니다.

호텔스닷컴 쿠폰 코드와 리워드 스탬프 비교

호텔스닷컴 리워드는 숙박 1박마다 스탬프 1개를 주고, 10개가 모이면 스탬프 10개 평균 요금만큼 1박을 무료로 줍니다. 1박 요금이 비슷하다면 스탬프 1개는 그 1박 요금의 10%와 같습니다. 그래서 실제 할인율이 10%를 넘는 코드만 스탬프를 포기할 이유가 됩니다.

쿠폰 코드 적용

호텔스닷컴 쿠폰 코드 현장결제도 되나요?

되지 않습니다. 예약할 때 전액을 내는 ‘지금 결제’ 요금을 골라야 결제 페이지에 코드 입력 칸이 생깁니다.

호텔스닷컴 쿠폰 코드 두 개를 같이 쓸 수 있나요?

한 예약에 하나만 들어갑니다. 할인 적용 금액 50만원 이하라면 SUMMER20, 넘으면 SPECIAL10처럼 금액을 보고 하나를 고릅니다.

호텔스닷컴 쿠폰 코드를 넣었는데 적용되지 않아요.

전용 링크 접속, 숙소 종류, 요금 옵션 세 가지를 확인합니다. 포털 광고 링크로 들어온 창, 글로벌 체인 호텔, 숙박 시 결제 요금에서는 코드가 적용되지 않습니다.

이미 결제한 호텔스닷컴 예약에 쿠폰 코드를 넣을 수 있나요?

소급 적용은 되지 않습니다. 무료 취소가 되는 요금이라면 취소 후 코드를 넣어 새로 예약하는 방법만 있습니다.

카드 할인

호텔스닷컴 카드 할인코드는 체크카드도 되나요?

카드사마다 다릅니다. 신한·우리·BC카드는 체크카드도 대상이고, KB국민·삼성·롯데카드는 개인 신용카드만, 현대카드는 체크카드를 뺀 국내외겸용 카드만 대상입니다.

호텔스닷컴 달러 결제는 어떻게 하나요?

카드 전용 페이지에서 넘어간 영문 페이지에서 예약합니다. 앱에서는 계정 → 보안 및 설정 → 앱 설정 → 통화 선택에서 결제 통화를 바꿉니다.

호텔스닷컴 카드 할인코드는 몇 번까지 쓸 수 있나요?

KB국민카드 10KBCARD와 NH 채움카드 NH10은 1인 5회입니다. 나머지 카드는 사용 횟수가 따로 공개되어 있지 않고, 아멕스 AMEX20은 준비된 수량이 떨어지면 끝납니다.

리워드·회원

호텔스닷컴 리워드 스탬프는 어떻게 쌓이나요?

숙박을 마친 1박마다 1개씩 쌓입니다. 로그인한 회원 예약만 대상이고, 쿠폰 코드·카드 할인코드를 쓴 예약이나 패키지 예약은 제외됩니다.

호텔스닷컴 스탬프에도 유효기간이 있나요?

12개월 동안 숙박을 마친 예약이 없으면 모두 만료됩니다. 적립한 스탬프와 아직 쓰지 않은 리워드 1박이 함께 사라집니다.

호텔스닷컴 회원가는 누구나 볼 수 있나요?

회원가입 후 로그인하거나 앱을 쓰면 볼 수 있습니다. 회원가는 최대 20%이고, 호텔이 회원가를 연 날짜에만 표시됩니다.

세일·기간

호텔스닷컴 가을 세일은 언제까지 예약해야 하나요?

2026년 10월 7일 오후 11시 59분(숙소 현지 시간)까지입니다. 이때 예약한 숙소는 2027년 3월 31일 투숙분까지 세일 요금이 적용됩니다.

2027년 여행 숙소에도 호텔스닷컴 쿠폰 코드를 쓸 수 있나요?

DT26과 LP005는 2027년 6월 30일 투숙분까지 적용됩니다. 두 코드 모두 2026년 9월 30일까지 예약해야 합니다.

호텔스닷컴 여러 호텔 할인은 모든 여행에 되나요?

두 숙소가 1,609km 이내, 날짜 차이 3일 이내일 때만 됩니다. 서울과 도쿄(약 1,153km)는 해당하지만 싱가포르와 발리(약 1,683km)는 해당하지 않습니다.
